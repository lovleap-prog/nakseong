# 공지사항 · 개인 메모 · 학사일정 · 출장

## 1. 공지사항 — 기간을 정해 한 번만 씁니다

[일일] 과 [주간] 이 **같은 공지를 봅니다.** 전에는 날짜마다 한 장, 주마다 한 장이라
같은 말을 두 번 써야 했고, 이틀 이어지는 공지는 한쪽에서 놓치곤 했습니다.

이제 **언제부터 언제까지**를 정해 한 번만 쓰면, 그 기간에 걸치는 날에 모두 뜹니다.

### 두 가지로 씁니다

**① 자유 메모 — 바로 적기**

상자 맨 위 칸에 적고 **엔터**를 치면 그대로 붙습니다. 창이 열리지 않습니다.
(Shift+엔터로 줄바꿈)

```
간단한 알림은 여기에 바로 적으세요 (기간 없이 계속 붙습니다)   [붙이기]
```

날짜를 정하지 않아 **내릴 때까지 계속** 붙어 있습니다. 기간 표시 자리에 초록색 `상시` 라고 나옵니다.
"교무실 복사기 토너 교체했습니다" 처럼 짧고 기한 없는 알림에 쓰세요.

**② 기간 공지 — [+ 기간 정해 쓰기]**

내용과 게시 기간을 정합니다.
`오늘만` · `이번 주` · `1주` · `한 달` 단추로 끝날짜를 빨리 정할 수 있습니다.
창 안의 **[기간 없이 계속 붙여두기]** 를 켜면 ①과 같아지고, 끄면 다시 기간제가 됩니다.

> 기간을 고르는 것이 번거로워 결국 안 쓰게 되는 짧은 알림이 많습니다.
> 그래서 ①을 함께 두었습니다. 둘은 같은 자리에 섞여 뜨고, `상시` 가 위로 옵니다.

- 📌 로 맨 위에 **고정**할 수 있습니다
- 끝나기 이틀 전부터 `2일 남음`, `오늘까지` 가 붙습니다
- 기간이 지나면 **저절로 내려갑니다** (상시 메모는 그대로 남습니다)

### 기간이 끝나면 — 더 붙여둘지 물어봅니다

게시가 끝난 내 공지가 있으면 공지 상자 위에 이렇게 뜹니다.

```
게시가 끝난 공지 1건이 있습니다. 더 붙여둘까요?
  지난 주 안내장 수합        9. 19.(토) 끝
  [1주 더] [한 달 더] [날짜 정하기] [내리기]
```

아직 수합이 안 끝났으면 [1주 더], 끝났으면 [내리기] 를 누르면 됩니다.
**쓴 사람과 관리자에게만** 보입니다. 다른 선생님 화면에는 안 나옵니다.

### 누가 쓰나 — 관리자 + 지정한 사람

관리자만 쓰게 두면 정작 알려야 할 사람이 못 씁니다.
**공문 접수나 안내장 수합을 담임 선생님께 알리는 일은 교무행정사가 합니다.**

[설정] → 명단 · 승인 에서 그분 줄의 **[공지 권한]** 을 누르면 됩니다.

| | 공지 쓰기 | 일정 승인·수정 |
|---|---|---|
| 관리자 | ○ | ○ |
| **공지 권한 받은 분** | ○ | **✕** |
| 교사 | ✕ | ✕ |

공지 권한은 **공지만** 열어줍니다. 일정 승인 권한은 따라오지 않습니다.
역할 칸에 초록색 `공지` 딱지가 붙어 누가 가졌는지 한눈에 보입니다.

- 자기가 올린 공지는 본인이 고치고 내립니다
- 남의 공지는 **관리자만** 고치고 내립니다
- 교사에게는 읽기만 보입니다. [+ 쓰기] 도 고치기 단추도 없습니다

> 파이어스토어를 쓰신다면 **보안 규칙을 다시 게시**하셔야 합니다.
> `docs/SETUP-firebase.md` 5번의 규칙에 `board` 항목과 `canPost()` 가 새로 들어갔습니다.

## 3. 학사일정 탭

### 달력 보기 · 목록 보기

기본은 **달력 보기**입니다. 학교가 쓰는 학사일정 문서가 원래 이 모양이고,
목록으로 늘어놓으면 주말이 어디인지 방학이 언제부터인지 알 수가 없습니다.

```
3월
 일   월   화   수   목   금   토
  1    2    3    4    5    6    7
삼일절 대체 시업식 사랑방 동아리
      휴일 입학식  모임  활동
```

| | |
|---|---|
| **주말** | 토·일 칸이 음영. 일요일 빨강, 토요일 파랑 |
| **공휴일** | 주황 칸 + 이름 |
| **방학** | 빗금 음영. 달 제목 옆에 `방학 7. 22.~8. 18.` |
| **오늘** | 파란 테두리 |
| **기간 행사** | 시작한 날에 `~13` 처럼 끝날이 붙습니다 |

- 칸의 행사를 **끌어서 다른 날로 옮길 수 있습니다**
- 눌러서 고칩니다
- 제목이 길면 두 줄까지 보이고 나머지는 `…` 입니다. **마우스를 올리면 전체**가 뜨고,
  [목록] 보기에서는 그대로 다 보입니다

**방학 구간**은 `방학식`(또는 `종업식`) 과 그 다음 `개학식`(또는 `시업식`) 사이로 잡습니다.
학사일정에는 그 두 날만 적혀 있고 사이가 방학이기 때문입니다.


**학사일정은 뼈대입니다.** 한 해 전체를 한 번 올려두고 기준으로 삼는 표입니다.
여기서 월간 계획을 자동으로 만들지 않습니다. 월간은 월중계획 한글 파일을 따로 올려서 채웁니다.

1학기 / 2학기를 나눠 담고 **월별로 묶어** 보여줍니다.

### 탭 맨 위 — 수업일수

학사일정 문서에 들어 있는 **학기별 수업일수 표**를 그대로 위에 붙입니다.

```
월       3월  4월  5월  6월  7월  소계
수업일수  21   22   18   21   14    96
```

아래에 `1학기 96일 · 2학기 95일 · 계 191일` 로 요약이 붙습니다.
문서에 이 표가 없으면 자리를 차지하지 않습니다.

### 학기별 표 아래 — 비급식일

`※ 비급식일(2일): 4.29.(수)-교육지원청 행사 일정에 따른 변동 가능, 7.15.(수)` 같은 줄을 읽어
**그 학기 표 아래에 딱지로** 붙입니다. 괄호 뒤에 붙은 단서도 함께 답니다.

비급식일은 해마다 바뀌므로 **관리자가 옮길 수 있습니다.**

- 딱지를 **끌어서** 다른 날짜 줄에 놓으면 그 날로 옮겨집니다
- 딱지를 누르면 날짜 칸이 열려 직접 고칠 수도 있습니다
- `✕` 로 지웁니다

### 일정도 끌어서 옮깁니다

학사일정 줄도 같은 방식입니다. 관리자가 줄을 **끌어다 다른 날에 놓으면** 날짜가 바뀝니다.
마우스는 조금 밀면 바로, 휴대폰·태블릿은 **길게 눌렀다가** 끌면 됩니다.
줄 오른쪽 날짜 칸을 눌러 직접 적어도 됩니다.

### 한글 파일로 올리기

[파일에서 가져오기] 에 학사일정 한글(.hwpx) 파일을 끌어다 놓으면 됩니다.
학교마다 표 모양이 달라서 흔한 네 가지를 모두 받습니다.

| 표 모양 | 예 |
|---|---|
| **달력형 (가장 흔함)** | 여러 달을 가로로 늘어놓고 달마다 `일 │ 요일 │ 행사` |
| 월·일 열이 갈린 것 | `3 │ 2 │ 월 │ 시업식` |
| 날짜 열 하나 | `3/2 │ 시업식`, `5/4~5/8 │ 현장체험학습 주간` |
| 한 칸에 여러 날 | `3월 │ 2(월) 시업식 ⏎ 9(월) 학부모총회` |
| 그냥 줄로 | `3/2 시업식` |

달력형은 이렇게 생긴 것입니다.

```
2026학년도 1학기
│   3월          │   4월          │   5월          │ …
│ 1 일 삼일절     │ 1 수 동아리활동 │ 1 금           │ …
│ 2 월 대체 휴일  │ 2 목           │ 2 토           │ …
```

- **1학기 표와 2학기 표를 한 번에** 읽어 각각 제자리에 넣습니다
- 문서에 `2026학년도` 가 있으면 **학년도를 자동으로 잡습니다.**
  학년도이므로 **1·2월은 이듬해**로 계산합니다 (2026학년도 1월 1일 → 2027-01-01)
- 칸이 병합돼 있어도 어긋나지 않습니다. 칸의 실제 주소를 읽어 격자에 앉힙니다
- 세로로 병합된 **주간 행사 띠**(예: 세로로 쓴 `학교세우기`)는 날짜별 행사로 넣지 않습니다
- 기간(`5/4~5/8`)은 종료일까지 넣습니다
- 수업일수 표는 **행사로 읽지 않고** 위쪽 통계 자리로 보냅니다

### 한 칸이 두 줄로 갈려 있어도 한 건입니다

한글에서 글자가 길면 한 칸 안에서 줄이 갈립니다. 이런 것은 **묶어 한 건으로** 넣습니다.
`시업식·입학식` 처럼 **정말 둘인 것만** 나눕니다.

괄호 안의 쉼표는 나누지 않습니다. `건강검진(1,4)` 는 학년을 적은 것이므로 **한 건 그대로**입니다.

### 8월은 문서가 아니라 학기 기간을 따릅니다

학사일정 문서는 문서 만들 때 편하려고 **8월 전체를 1학기 표에 넣어두는 경우가 많습니다.**
문서 안에 적힌 학기 기간

```
1학기 (2026.03.01. ~ 2026.08.18.)
2학기 (2026.08.19. ~ 2027.02.28.)
```

을 읽어 **날짜로 다시 갈라 넣습니다.** 8/14·15·17·18 은 1학기에, **8/19 개학식부터는 2학기**에 들어갑니다.
문서에 학기 기간이 없으면 표에 적힌 대로 둡니다.

그 날짜의 학사일정은 **[일일] 화면에도** 함께 뜹니다.

## 4·5. 개인 메모 — 나에게만 보입니다

바탕화면 스티커처럼 씁니다. **다른 선생님에게는 절대 보이지 않습니다.**
(개인 확인 체크와 같은 방식으로, 파이어스토어에서도 본인 문서만 읽고 씁니다)

### 어디서 쓰나

| 곳 | 무엇 |
|---|---|
| 머리말 **[📝 메모]** | 화면 오른쪽 아래 서랍. 어느 탭에서나 열어둘 수 있습니다 |
| [일일] 맨 아래 | 그 날짜에 걸린 메모 + 새 메모(그 날짜로 붙음) |
| [주간] · [월간] | 그 기간에 걸린 메모 |

### 세 가지로 씁니다

1. **그냥 메모** — 생각날 때 적어두는 쪽지
2. **체크리스트** — `✓` 단추로 바꾸면 체크칸이 생기고, 체크하면 줄이 그어집니다
3. **기간이 있는 할 일** — `+ 기간 넣기` 로 날짜를 넣으면
   **일일·주간·월간 화면에 함께 뜹니다.** 기간이 지나면 빨갛게 `지남` 이 붙습니다

그 밖에 **📌 고정**(맨 위로), **◐ 색 바꾸기**(5색), 서랍의 **[끝난 것 치우기]** 가 있습니다.
엔터로 저장, Shift+엔터로 줄바꿈입니다.

> 개인 메모는 **백업 파일에 들어가지 않습니다.** 사람마다 다른 값이라 남의 것까지 덮어쓸 이유가 없습니다.

## 6. 출장 현황 탭

### 신청

[+ 출장 신청] → 날짜·사유·장소를 적습니다.
**보결이 필요합니다** 를 체크하면 **보결 내용** 칸이 열립니다.

> 보결은 남이 대신 들어가 줘야 하는 일이라 **몇 교시에 무엇이 필요한지가 핵심**입니다.
> 그래서 체크만 하고 내용을 비우면 저장되지 않습니다.
> `3~4교시 3학년 2반 수학` 처럼 교시와 학급을 적어주세요.

- 교사가 신청하면 **확인 대기**, 관리자가 넣으면 바로 등록됩니다
- 관리자가 승인·반려합니다. 반려하면 사유가 신청자에게 보입니다
- 대기 중인 자기 신청은 본인이 고치거나 지울 수 있습니다

### 보결 배정 — 누가 들어가는지 정하기 (관리자만)

신청자가 적는 **보결 내용**은 '무엇이 필요한지' 입니다. 거기에 **누가 들어가는지**를
관리 선생님이 얹습니다.

**보결이 필요한 날이면** [일일] 화면 위쪽(확인 대기 바로 아래)에 체크리스트가 뜹니다.
필요 없는 날에는 아예 나오지 않습니다.

```
🙋 보결 배정  1/2                       [1건 남음]  [📋 보결 안내 복사]

 ▢  이정아   미배정   유치원 협의회
    요청: 종일
    아직 들어갈 분을 정하지 않았습니다.                        [배정하기]

 ✔  조요한   배정 완료   교육지원청 연수
    요청: 1-2교시: 5학년/3교시: 3학년/4교시: 4학년/5교시: 교담
    1-2교시 5학년 → 김용신
    3교시 3학년 → 정하늘아 …                                   [고치기]
```

- **[배정하기]** 를 누르면 `교시 / 학급·과목 / 들어갈 분 / 비고` 칸이 열립니다
- 신청자가 적은 요청 글(`1-2교시: 5학년/3교시: 3학년`)을 보고 **교시를 미리 끊어 둡니다.**
  틀린 곳만 고치시면 됩니다
- 들어갈 분 칸은 **업무분장 명단과 로그인 명단에서 이름을 골라** 넣습니다
- 들어갈 분을 비워 두면 `덜 됨` 으로 남습니다. 정해지면 다시 와서 채우세요
- [일일] 맨 위 요약 줄의 **보결** 칸은 **아직 못 정한 건이 있을 때** 주황으로 섭니다

### 누가 들어가는지 알리기

정해 두면 **세 곳으로 저절로 나갑니다.** 따로 적어 돌리지 않으셔도 됩니다.

| 어디로 | 무엇이 |
|---|---|
| **들어가실 선생님 화면** | 그분의 [일일] 맨 위에 `🙋 오늘 보결이 N건 있습니다` 주황 띠. 위젯 창에도 뜹니다 |
| **일일 안내문** | `4. 조요한 보결` 아래 `1-2교시: 5학년(김용신)/3교시: 3학년(정하늘아)` |
| **메신저** | [📋 보결 안내 복사] 로 아래 글을 만들어 바로 붙여넣기 |

```
[10월 14일(수) 보결 안내]

▷ 조요한 선생님 출장 (교육지원청 연수)
  · 1-2교시 5학년 → 김용신
  · 3교시 3학년 → 정하늘아
  · 4교시 4학년 → 진치훈
  · 5교시 교담 → 박세라
```

|---|---|
| [일일] 화면 | 보결이 필요한 날에만 **보결 배정 체크리스트** (관리자만) |
| [일일] 화면 | 내가 들어가는 보결이 있으면 맨 위에 주황 띠 (모두) |
| [출장] 탭 맨 위 | 보결이 필요한 출장 표 — 날짜·신청자·사유·**요청**·**배정** |
| [출장] 탭 | 앞으로 / 이번 달 / 전체 / 내 신청 으로 걸러 보기 |
| [일일] 출장 칸 | 출장자 이름표. 배정이 끝났으면 요청 대신 **누가 들어가는지**를 적습니다 |

보결 내용을 비워둔 건은 **`교시 미기재`** 로, 아직 사람을 못 정한 건은 **`미배정`** 으로
빨갛게 나옵니다.

## 7. 법정공휴일 · 휴업일

쉬는 날은 **한 곳에서 판정해 일일·주간·월간·시간표가 함께 따릅니다.**

### 어디서 알아내나

| 출처 | 무엇 |
|---|---|
| **앱에 들어 있는 목록** | ① 날짜가 해마다 같은 공휴일 — 신정·삼일절·어린이날·현충일·광복절·개천절·한글날·성탄절<br>② **설날·부처님오신날·추석 (2026~2032년)** — 설과 추석은 전날·당일·다음날 사흘 모두 |
| **학사일정 탭** | **대체휴일·재량휴업일·개교기념일**처럼 학교마다 다른 날. 2033년 이후의 음력 공휴일도 여기서 읽습니다. 앱에 들어 있는 목록보다 **늘 우선**합니다 |
| **관리자가 손으로** | 학사일정 줄의 🛌 단추. 위 둘을 덮어씁니다 |

**학사일정을 안 올려도 추석·설날까지 잡힙니다.** 올려두면 그 학교의 대체휴일·재량휴업일까지 한 번에 맞춰집니다.

> **대체공휴일은 앱에 넣지 않았습니다.** 대체공휴일 규칙은 법이 몇 번 바뀌었고
> 앞으로도 바뀝니다. 하루라도 틀리면 **수업하는 날을 '쉬는 날' 로 적게 되는데**,
> 그것은 빠뜨리는 것보다 나쁩니다. 학사일정에 `대체 휴일` 이라고 적혀 있으면
> 그것을 그대로 읽습니다.
>
> 음력 공휴일 날짜는 천문 계산으로 뽑은 뒤 2020~2030년 실제 달력과 하나씩
> 맞춰 본 것입니다. 2026년 추석(9.25)은 학교 학사일정 문서와도 같았습니다.

### 어떻게 보이나

| 화면 | |
|---|---|
| **월간** | 그 칸이 주황색이 되고 아래에 이름이 붙습니다 (`추석연휴`) |
| **주간** | 날짜 칸이 주황색이 되고 요일 아래에 이름이 붙습니다 |
| **일일** | 맨 위에 `🛌 추석 — 수업이 없는 날입니다` 가 뜹니다 |
| **시간표** | 그 요일이 주황색이 되고 빈 칸에 빗금이 갑니다 |

### 시간표를 안 넣어도 됩니다

쉬는 날의 빈 칸은 **빗금으로 흐리게** 둡니다. "여기는 채울 필요 없다" 는 표시입니다.
**막지는 않았습니다.** 쉬는 날에 돌봄교실이나 방과후를 적어두는 학교가 있어서,
넣고 싶으면 그대로 넣을 수 있습니다.

### 반복일정은 쉬는 날에 돌지 않습니다

아침 독서활동이나 화요일 스포츠클럽이 **추석에 뜨면 계획표가 틀린 것**이고,
중복 판정까지 함께 어긋납니다. 그래서 쉬는 날에는 반복일정을 내보내지 않습니다.
결재 문구와 주간·월중 서식에서도 자동으로 빠집니다.

### 잘못 잡았을 때

학사일정 제목으로 짐작하므로 틀릴 수 있습니다. 그 줄의 **🛌** 를 누르면 됩니다.

- 꺼져 있는데 쉬는 날이면 → 눌러서 켭니다 (재량휴업일 등)
- 켜져 있는데 수업하는 날이면 → 눌러서 끕니다

**방학식·개학식·시업식은 수업이 있는 날**이라 자동으로 잡지 않습니다.
방학 기간은 학사일정에 하루짜리로 적히는 일이 많아 역시 자동으로 잡지 않으니,
필요하면 손으로 켜주세요.

## 8. 배차

현장체험학습처럼 **차를 불러야 하는 활동**은 교무행정사가 미리 배차를 신청해야 합니다.
그러려면 한 달 치를 미리 볼 수 있어야 합니다.

### 넣기

일정을 추가·수정할 때 **[🚌 배차가 필요합니다]** 를 체크하면 **배차 내용** 칸이 열립니다.

```
🚌 배차가 필요합니다
  배차 내용  9:00 출발, 순천만생태교육문화원, 3~4학년 48명
```

> 체크만 하고 내용을 비우면 저장되지 않습니다.
> 정작 신청할 때 출발 시각과 가는 곳을 다시 물어봐야 하기 때문입니다.

### 보는 곳

| 곳 | 무엇 |
|---|---|
| **[월간] 달력 아래** | 그 달 배차 필요 활동만 모은 표 (날짜·활동·대상·배차 내용·담당) |
| [월간] 달력 칸 | 🚌 가 붙고 글자가 진해집니다 |
| [일일] · [주간] 카드 | `🚌 배차` 딱지. 마우스를 올리면 배차 내용이 보입니다 |

아직 승인되지 않은 건은 표에서 주황색으로 나오고 `확인 대기` 가 붙습니다.
배차 내용을 비워둔 건은 빨갛게 `내용 미기재` 로 나옵니다.

## 9. 비고는 좁은 칸에서도 보입니다

`1-5교시` 처럼 시간만 적어두면 그 안에서 무슨 순서로 도는지 알 수가 없습니다.
그래서 **세부 내용(비고)을 주간·월간의 좁은 칸에서도** 보여줍니다.

```
1-5교시
영어원어민 순회
[정하늘] [영어]
6-5-3-4-6년 순      ← 비고
```

학년별로 칸을 다섯 개 만드는 것보다 이렇게 한 줄로 두는 편이 읽기 편합니다.
