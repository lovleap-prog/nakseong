# 구글 시트에서 교육활동 받아오기 — 한 단계씩

각 계 담당자가 **쓰던 구글 시트를 그대로 두고**, 앱으로 한 번에 받아옵니다.
시트 모양을 고칠 필요가 없습니다.

읽을 수 있는 시트는 셋입니다.

| 모양 | 생김새 |
|---|---|
| **월간 시트** | 왼쪽에 `1 2 3 …` 날짜, 오른쪽에 그 날 할 일을 쉼표로 이어 적은 것 |
| **주간 시트** | `날짜 · 요일 · 계 · 담당자 · 주요 업무 내용 · 시간 · 장소` 표 |
| **자유입력 시트** | 형식 없이 적은 글 |

한 문서에 월간·주간 시트가 여러 장 있어도 됩니다. 한꺼번에 읽습니다.

---

## 1단계 — 스크립트 붙여넣기 (처음 한 번만)

1. 교육활동을 적는 **구글 시트 문서**를 엽니다
2. 위 메뉴 **확장 프로그램 → Apps Script**
3. 열린 편집기의 내용을 **모두 지우고**, 이 저장소의 **`sheets/Code.gs`** 를 통째로 붙여넣습니다
4. 위쪽 **💾 저장**
5. 구글 시트 탭으로 돌아와 **새로고침(F5)**
6. 메뉴에 **[교육활동]** 이 생깁니다

## 2단계 — 시트 이름에 달을 적어두기

월간 시트는 **몇 월인지** 알아야 날짜를 만들 수 있습니다. 둘 중 하나면 됩니다.

- 시트 **이름**에 달이 들어가게: `10월`, `10월 계획`, `2026-10`
- 또는 시트 **맨 위 칸(A1)** 에 `10월`

> 주간 시트는 날짜 칸에 `10월5일` 처럼 적혀 있으므로 따로 할 일이 없습니다.
> 연도는 시트 이름이나 문서 이름의 `2026` 을 씁니다. 없으면 올해로 봅니다.

## 3단계 — 정리하기

메뉴 **[교육활동] → [정리하기 (모든 시트)]**

- 처음 누르면 구글이 **권한을 묻습니다.** [권한 검토] → 계정 선택 →
  "이 앱은 확인되지 않았습니다" 가 나오면 **[고급] → [<문서이름>(으)로 이동]** → **[허용]**
  (내 시트를 내가 만든 스크립트가 읽는 것이라 안전합니다)
- 끝나면 **`정리됨`** 시트가 생기고, 몇 건을 읽었는지 시트별로 알려줍니다

`정리됨` 시트의 열은 이렇습니다.

```
날짜 | 종료일 | 시간 | 활동명 | 대상 | 장소 | 담당 | 부서 | 비고
```

**여기서 눈으로 한 번 확인하세요.** 날짜가 밀렸거나 활동명이 이상하면 이 시트에서
고치면 됩니다. (원래 시트를 고치고 다시 [정리하기] 를 눌러도 됩니다)

> 재량휴업일·개천절·한글날 같은 **쉬는 날 줄은 건너뜁니다.** 학사일정은 [학사일정] 탭에서
> 따로 올립니다. 비고 칸의 메모('이전' 등)도 일정으로 보지 않습니다.

## 4단계 — 웹앱으로 배포 (처음 한 번만)

1. Apps Script 편집기 오른쪽 위 **[배포] → [새 배포]**
2. 톱니바퀴 ⚙ → **웹 앱**
3. 설명: `교육활동 가져오기`
4. **실행 계정: 나**
5. **액세스 권한이 있는 사용자: 모든 사용자**
6. **[배포]** → 나온 **웹 앱 URL**(`.../exec` 로 끝남)을 복사

> **왜 '모든 사용자' 인가** — 앱이 이 주소를 부를 때는 구글 로그인 정보가 실리지
> 않습니다. 그래서 '**Google 계정이 있는 모든 사용자**' 로 두면 앱에서 못 읽습니다.
> (학교 구글 계정이 아닌 개인 지메일로 만들면 '조직 내 사용자' 항목은 아예 안 뜹니다)

### 열쇠말 걸기 (권장)

'모든 사용자' 로 두면 **주소를 아는 사람은 누구나** `정리됨` 시트를 읽습니다.
거기엔 담당 선생님 실명이 들어갑니다. 주소가 새도 막히도록 열쇠말을 겁니다.

1. Apps Script 편집기 맨 위쪽 `var READ_KEY = '';` 를 찾습니다
2. 따옴표 사이에 아무 말이나 적습니다 — `var READ_KEY = 'nakseong2026';`
3. 💾 저장 → **[배포] → [배포 관리] → ✏ → 버전 '새 버전' → [배포]**
4. 앱에 넣을 주소는 **뒤에 `?key=` 를 붙인 것**입니다

```
https://script.google.com/macros/s/.../exec?key=nakseong2026
```

열쇠말을 비워 두면(`''`) 검사하지 않습니다.

> 그래도 바깥에 열어두는 게 마음에 걸리시면, 배포하지 말고 **시트를 CSV로 내려받아**
> 앱 [불러오기] 탭에 올리셔도 됩니다. 결과는 같습니다.

## 5단계 — 앱에서 받아오기

1. 앱 **[불러오기]** 탭 → 맨 아래 **구글시트에서 가져오기**
2. 복사한 `/exec` 주소를 넣고 **[가져오기]**
3. 표로 미리 보입니다. 체크를 끄면 그 줄은 빼고 올라갑니다
4. **[등록하기]**(관리자) 또는 **[제출(확인 요청)]**(선생님)

주소는 그 컴퓨터에 기억됩니다. 다음부터는 [가져오기] 한 번이면 됩니다.

---

## 다음 달에는

1. 시트에 그 달 내용을 적습니다 (평소 하시던 대로)
2. **[교육활동] → [정리하기]**
3. 앱 [불러오기] → **[가져오기]** → **[등록하기]**

스크립트 붙여넣기와 배포는 **다시 하지 않습니다.**

## 잘 안 될 때

| 증상 | 까닭과 손보는 법 |
|---|---|
| 메뉴에 [교육활동] 이 없다 | 저장 후 시트를 **새로고침** 하지 않았습니다 |
| 날짜가 다 비어 있다 | 월간 시트의 **달**을 못 찾았습니다. 시트 이름을 `10월` 로 바꾸세요 |
| 연도가 작년/올해로 나온다 | 시트나 문서 이름에 `2026` 을 넣으세요 |
| 한 칸에 적은 여러 일이 한 건으로 붙는다 | 활동 사이를 **쉼표(,)** 로 끊어주세요. 괄호 안 쉼표는 그대로 둬도 됩니다 |
| 주간 시트가 안 읽힌다 | 머리글에 **날짜**, **담당자** 또는 **주요 업무 내용** 이 있어야 합니다 |
| 앱에서 "시트를 찾을 수 없습니다" | 시트에서 **[정리하기]** 를 먼저 누르세요 (`정리됨` 시트가 있어야 합니다) |
| "열쇠말이 맞지 않습니다" | 주소 끝의 `?key=…` 가 `READ_KEY` 와 같아야 합니다 |
| 가져오기를 눌러도 아무것도 안 온다 | 배포 액세스가 **모든 사용자** 여야 합니다. 'Google 계정이 있는 모든 사용자' 로는 앱이 못 읽습니다 |
| 붙여넣다 중간에 잘렸다 (`Unexpected end of input`) | 깃허브 화면 대신 **raw 주소**에서 `Ctrl+A` → `Ctrl+C` 로 복사하세요. 맨 끝 줄 번호가 **416** 이어야 합니다 |
| 스크립트를 고쳤는데 그대로다 | **[배포] → [배포 관리] → ✏ → 버전 '새 버전' → [배포]** 를 해야 반영됩니다 |

## 이렇게 읽힙니다 (보기)

**월간 시트**

```
6 | 화 | 학교스포츠클럽(10:30, 부서별 장소), 학부모동아리(19:00, 백이관)
```
→ 2건으로 나뉩니다

| 날짜 | 시간 | 활동명 | 장소 |
|---|---|---|---|
| 2026-10-06 | 10:30 | 학교스포츠클럽 | 부서별 장소 |
| 2026-10-06 | 19:00 | 학부모동아리 | 백이관 |

`학교폭력예방교육 및 인성교육실천주간(~17)` 처럼 적으면 **12일~17일 기간 일정**이 됩니다.

**주간 시트**

| 날짜 | 요일 | 계 | 담당자 | 주요 업무 내용 | 시간 | 장소 |
|---|---|---|---|---|---|---|
| 10월6일 | 화 | 연구 | 김용신 | 전문적학습공동체(목공예) | 15:00~16:40 | 방실방실 |

→ 담당·계·시간·장소가 그대로 들어갑니다. 날짜 칸이 **병합**돼 있어도 아래 줄들이
같은 날짜를 이어받습니다.
