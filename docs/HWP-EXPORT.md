# 한글 파일 · 결재 문구 내보내기

## 어디서 하나

- **일일**: [결재문구·한글파일] 버튼
- **주간**: [주간활동계획 내보내기] 버튼
- **월간**: [월중계획 내보내기] 버튼
- **방과후**: [표 내보내기] 버튼

## 주간·월간은 **학교 서식**으로 나갑니다

전에는 줄글로만 나갔습니다. 그러면 결재를 올릴 수가 없습니다.
업무포털에 올릴 문서는 학교가 쓰던 **표 서식**이어야 하기 때문입니다.
그래서 주간·월간 내보내기는 이제 실제 학교 문서와 같은 표로 만듭니다.

창을 열면 위에 칸이 나뉘어 있습니다.

| 칸 | 담기는 것 |
|---|---|
| **학교 서식** | 주요 교육활동 표 + 그 주 교담 시간표 (기본) |
| **주요 활동만** | 주요 교육활동 표만. *주간에만 있습니다* |
| **줄글 요약** | 메신저·밴드에 붙일 줄글 |

시간표가 그 주에 바뀔 일이 없으면 굳이 같이 돌릴 것이 없습니다.
그럴 때 **[주요 활동만]** 을 고르고 내려받으면 표 한 장으로 나갑니다.
파일 이름에도 `주간활동계획(주요활동)_…` 처럼 표시됩니다.
인쇄·[한글용 HTML]·[한글(.hwpx)] 모두 **그때 골라 둔 칸 그대로** 나갑니다.

내려받기 전에 **표가 그대로 미리 보입니다.** 보고 나서 [인쇄] · [한글용 HTML] · [한글(.hwpx)] 중에 고르면 됩니다.

### 주간활동계획

```
9월 1주(26.8.31.-9.5.) 주요 교육활동
┌──────┬──────┬────────┬───────────────────────┬───────┬──────────┐
│ 날짜 │  계  │ 담당자 │    주요 업무 내용     │ 시간  │   장소   │
│(요일)│      │        │                       │       │          │
├──────┼──────┼────────┼───────────────────────┼───────┼──────────┤
│ 9.1  │ 체육 │ 강도현 │ 학교스포츠클럽        │ 10:30 │ 부서별…  │
│ (화) ├╌╌╌╌╌╌┼╌╌╌╌╌╌╌╌┼╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌╌┼╌╌╌╌╌╌╌┼╌╌╌╌╌╌╌╌╌╌┤ ← 옅은 바탕
│      │ 출장 │ 최영호 │ 현장체험학습 매뉴얼…  │ 13:00 │ 교육문…  │
│      │      │        │ - 보결 필요: 5,6교시  │       │          │
├──────┼──────┼────────┼───────────────────────┼───────┼──────────┤
│ 9.24 │      │        │ 추석 연휴             │       │          │ ← 옅은 바탕
│ (목) │      │        │                       │       │          │
└──────┴──────┴────────┴───────────────────────┴───────┴──────────┘
```

- **날짜 칸은 세로로 병합**됩니다. 그 날 일정이 몇 건이든 날짜는 한 번만 적힙니다
- **계 = 부서**, **담당자 = 담당 선생님**입니다. 업무분장표를 올려두면 자동으로 채워집니다
- 세부 내용은 제목 아래에 `- ` 로 붙습니다
- **출장도 한 줄로 들어갑니다.** 계는 `출장`, 보결이 필요하면 `- 보결 필요: 5,6교시 3-1반` 까지 적힙니다.
  주간계획을 보는 선생님이 보결을 미리 알 수 있어야 하기 때문입니다
- **출장 줄은 연한 노란 바탕**입니다. 그 날 누가 자리를 비우는지가 한눈에 들어와야 하기 때문입니다.
  줄 걸러 까는 회색보다 앞섭니다
- **교담·특별실 시간표는 2쪽에서 시작합니다.** 1쪽은 주요 교육활동, 2쪽은 교담입니다.
  결재에 올릴 때 쪽이 섞이지 않습니다. [주요 활동만] 을 고르면 1쪽만 나옵니다

### 2쪽 — 교담·특별실 시간표

```
┌────────────┬──────┬──────────────┬──────────┬──────────┬──────┐
│            │  월  │      화      │    수    │    목    │  금  │  ← 회색
├────────────┼──────┼──────────────┼──────────┼──────────┼──────┤
│   1교시    │      │ 꿈자람반1,2  │꿈자람반1,2│꿈자람반5,6│     │
│  ↑ 회색    │      │ 영어6(원어민)│          │          │      │
├────────────┼──────┼──────────────┼──────────┼──────────┼──────┤
│   5교시    │      │영어5,6(원어민)│         │          │      │
├────────────┴──────┴──────────────┴──────────┴──────────┴──────┤
│                        방과후학교                              │  ← 옅은 파랑 띠
├────────────┬──────┬──────────────┬──────────┬──────────┬──────┤
│13:20~14:00 │      │   피아노1    │          │ 뮤지컬2  │      │
│  ↑ 옅은 파랑│     │              │          │          │      │
├────────────┼──────┼──────────────┼──────────┼──────────┼──────┤
│    장소    │      │              │          │          │      │  ← 회색
│    비고    │      │              │          │          │      │
└────────────┴──────┴──────────────┴──────────┴──────────┴──────┘
```

- **교시 칸은 회색**, **방과후는 옅은 파랑**입니다. 성격이 다른 시간이라 갈라 둡니다
- 그 사이에 **`방과후학교` 가로 띠**를 한 줄 둡니다
- **`13:20~14:00` 은 한 줄에** 들어갑니다. 첫 칸을 11.7% → 15% 로 넓혔습니다
- **장소·비고** 줄은 회색으로 깔아 표의 바닥임을 보입니다

> 색은 아주 옅게 썼습니다(`#FFF7D6`·`#EAF1FA`·`#F2F2F2`). 흑백으로 뽑아도 글씨가 묻히지 않습니다.
- 그 주 공지사항이 있으면 표 아래에 `※` 로 한 줄 붙습니다
- **하루에 두 건 이상이면** 그 사이를 **점선**으로 끊고 **한 줄 걸러 옅은 바탕**을 깝니다.
  어디까지가 같은 날인지 눈으로 바로 갈라집니다. 실제 학교 문서도 꼭 이렇게 되어 있습니다
- **법정공휴일**(추석·설 연휴, 삼일절, 개천절 …)도 **한 줄로 들어갑니다.**
  칸 전체에 옅은 바탕이 깔립니다. 연휴가 든 주도 월~토가 온전히 서야 하기 때문입니다.
  학사일정 탭에 넣어둔 재량휴업일·개교기념일도 같이 봅니다

**몇 월 몇째 주인가**는 그 주 **목요일이 든 달**로 셉니다.
8.31(월)~9.5(토) 주는 `9월 1주` 가 됩니다. 달을 걸친 주를 학교에서 부르는 방식과 같습니다.

### 월중 교육활동계획

```
┌───────────────────────────────────────────────────┐
│              2026년 9월 교육활동계획              │
│                   ○○초등학교                     │
└───────────────────────────────────────────────────┘
┌───┬────┬─────────────────────────────────┬────────┐
│ 일│요일│         주요 업무 내용          │  비고  │
├───┼────┼─────────────────────────────────┼────────┤
│ 1 │ 화 │ 양성평등교육주간(~4), 학교스포…  │        │
│ 30│ 수 │ 출결마감                        │비급식일│
├───┴────┼─────────────────────────────────┼────────┤
│  월별  │ ․ 따뜻하고 행복한 학교문화…      │수업일수│
│ 교육 활│                                 │ (급식) │
│ 동 중점│                                 │20일(19)│
└────────┴─────────────────────────────────┴────────┘
```

- 한 칸에 `제목(기간, 대상, 시간, 장소)` 로 적습니다. 실제 문서의 괄호 차례 그대로입니다
- **기간 일정은 시작한 날에 한 번만** 나오고 `(~4)` 가 붙습니다. 나흘 내내 같은 줄이 서지 않습니다
- **글이 칸 한가운데서 끊기지 않습니다.** 사람이 손으로 짜 넣듯 두 가지를 합니다.
  1. 한두 글자가 넘치면 **자간을 −4% 또는 −8%** 로 좁혀 한 줄에 앉힙니다
  2. 그걸로 안 되면 **항목이 시작되는 자리에서 줄을 바꿉니다.** 항목을 반으로 자르지 않습니다

  ```
  전:  … 학교스포츠클럽(10:30, 부서별 장소), 영어원어민 순회(6-5-
       3-4-6, 1-5교시, 각 교실 및 도서관), 전문적학습공동체(15:00, …
  후:  2학년 우쿨렐레 공연(10:30, 중앙 계단), 학교스포츠클럽(10:30, 부서별 장소),
       영어원어민 순회(6-5-3-4-6, 1-5교시, 각 교실 및 도서관),
       전문적학습공동체(15:00, 방실방실), 학부모동아리(19:00, 백이관)
  ```

  담당자가 둘이면 **한 줄에 한 사람씩** 세웁니다 (`정하늘아` / `오진영`).
  전에는 `정하늘 / 아, 오진영` 으로 이름 한가운데가 끊겼습니다.
  글자 폭은 재지 않고 어림합니다(한글 한 칸, 숫자·영문 반 칸). 틀려도 줄이 하나 느는 정도입니다.
- **비고 칸에 `비급식일`** 이 뜹니다. 학사일정 탭에 넣어둔 것과, 붙여넣기로 들어와
  일정 세부 내용에 붙은 표시를 함께 봅니다(세부 내용 쪽 표시는 문서 본문에서는 지웁니다)
- **주말(토·일)과 법정공휴일 줄에는 옅은 바탕**이 깔립니다. 수업일이 한눈에 세어집니다.
  공휴일 이름이 학사일정에 없더라도 `추석 연휴` 처럼 앞세워 적힙니다
- 맨 아래에 **[월간] 화면의 중점지도 내용**과 **수업일수(급식일수)** 가 들어갑니다.
  수업일수는 학사일정 탭의 수업일수 표에서, 급식일수는 거기서 비급식일을 뺀 값입니다

### 반복일정은 요일제만, 그것도 켜 둔 것만

아침 독서활동처럼 **매일 도는 것은 빼고**, 화요일 스포츠클럽·학부모동아리처럼
**요일제로 도는 것만** 넣습니다. 날마다 같은 줄이 반복되면 계획표를 읽을 수 없고,
실제 학교 문서도 그렇게 쓰여 있습니다.

그 위에 **[반복일정] 탭의 `주간·월간` 체크**를 봅니다. 꺼 두면 주간계획과 월중계획
어느 쪽에도 낱개로 서지 않습니다. 아침책다방처럼 늘 있는 것은 주마다 스무 번,
달마다 백 번씩 되풀이돼 피로하기만 하기 때문입니다.

**일일 화면과 나이스 결재 문구에는 꺼 두어도 그대로 나옵니다.** 거기서는 그게 맞기 때문입니다.

### 인쇄

[인쇄] 를 누르면 **화면에 보이는 그 서식 그대로** 종이에 나갑니다. A4 세로입니다.
새 창을 띄우지 않아서 휴대폰이나 팝업을 막아둔 학교 컴퓨터에서도 됩니다.
앱 화면(탭·단추)은 인쇄에서 빠지고, 표 머리줄은 장이 넘어가도 다시 찍힙니다.

## 두 가지 문구

| | 쓰임 |
|---|---|
| **나이스 결재용** | 나이스 일일교육활동 기안 본문에 그대로 붙여넣는 형식 (`1. 교육활동 / 가. …`) |
| **메신저 안내용** | 교직원 메신저·밴드에 올리는 안내문. 결재 문구 대신 써도 됩니다. |

두 문구 모두 **반복(상시) 일정과 방과후학교가 포함**됩니다.
체크박스로 뺄 수도 있고, 창 안에서 문구를 직접 고친 뒤 복사·내려받기 하면 고친 그대로 나갑니다.

예시:

```
2026. 9. 22.(화) 일일교육활동 계획

1. 교육활동
  가. 1~2교시 3학년 안전교육(시청각실, 김민수)
  나. 4교시 5학년 공개수업

2. 상시·반복 운영 활동
  가. 08:40~09:00 전교생 아침독서(각 교실)

3. 방과후학교 (1강좌)
  가. 15:00~16:40 창의로봇과학(과학실, 이수진) / 3~4학년

위와 같이 2026. 9. 22.(화) 일일교육활동을 실시하고자 합니다.
```

## 내려받기 형식 세 가지

### 1. 한글(.hwpx) — 권장, 베타

한글 2010 이상이 쓰는 표준 형식(OWPML)으로 직접 만듭니다. 변환기나 서버가 필요 없습니다.
**한컴오피스 한글 2014 이상**에서 바로 열립니다.

> **베타인 이유**: 한글 버전과 설치 환경에 따라 드물게 "문서 형식이 올바르지 않습니다"가 뜰 수 있습니다.
> 그럴 때는 아래 2번을 쓰세요. 내용은 완전히 같습니다.

**표도 들어갑니다.** 주간활동계획·월중계획 서식은 칸 병합(가로·세로)까지 그대로 나갑니다.
실제 학교 문서의 표 구조(`hp:tbl`)를 그대로 본떠 만들었고, 열 너비 비율도 옮겨왔습니다.
같은 날을 끊는 **점선**과 **옅은 바탕**도 한글 쪽 테두리·바탕(`borderFill`)으로 나가므로,
화면에서 본 모양이 한글에서도 그대로 나옵니다.

일일 나이스 결재 문구는 원래 줄글이라 그대로 문단으로만 만듭니다.

### 2. 한글용 HTML(.html) — 가장 확실함

한글에서 **[불러오기] → 파일 형식 "HTML 문서"** 로 열면 A4 세로 서식과 **표까지 그대로** 들어옵니다.
칸 병합도 살아납니다. **1번이 안 열리면 여기로 오시면 됩니다.** 내용은 똑같습니다.
연 뒤 [다른 이름으로 저장 → 한글 문서(.hwp)] 하면 결재 첨부로 쓸 수 있습니다.

### 3. 복사

클립보드로 복사합니다. 나이스 기안 화면이나 메신저에 그대로 붙여넣으면 됩니다.
**가장 빠른 길이고, 대부분은 이것으로 충분합니다.**

## 올릴 때 (업로드)

[불러오기] 탭에서 받는 형식:

| 형식 | 처리 |
|---|---|
| `.hwpx` | 표가 있으면 표를, 없으면 문단 글을 해석 |
| `.xlsx` | 첫 시트를 표로 읽음 |
| `.csv` / `.tsv` | 표로 읽음 |
| `.txt` | 자유 형식 글로 해석 |
| `.hwp` (구버전) | **바로 못 읽습니다.** 한글에서 [다른 이름으로 저장 → HWPX 문서] 로 저장해 올려주세요 |

구버전 `.hwp` 는 압축된 이진 형식이라 브라우저에서 바로 풀 수 없습니다.
hwpx로 한 번 저장하는 것이 가장 간단하고, 한글 2010 이상이면 모두 지원합니다.

### 월중 교육활동계획 표

학교에서 쓰는 **월중계획 한 장짜리 표**를 그대로 올리면 됩니다.

| 일 | 요일 | 주요 업무 내용 | 비고 |
|---|---|---|---|
| 1 | 화 | 양성평등교육주간(~4), 학교스포츠클럽(10:30, 부서별 장소), 영어원어민 순회 | |

이렇게 읽습니다.

- **한 칸에 쉼표로 나열된 일정을 각각 따로** 뽑습니다. 위 한 줄은 3건이 됩니다.
  괄호 안의 쉼표(`10:30, 부서별 장소`)는 구분자로 보지 않습니다.
- 날짜 칸에 `1` 만 있어도, 문서 제목의 **`2026년 9월`** 을 찾아 `2026-09-01` 로 만듭니다.
- `활동명(시간, 대상, 장소)` 형식에서 시간·대상을 먼저 걷어내고 **남은 것을 장소로** 봅니다.
  그래서 `AI교실`, `별초병설유`, `부서별 장소` 처럼 목록에 없는 장소도 잡힙니다.
- `(~4)` 는 **4일까지 이어지는 기간**으로 읽어 종료일을 채웁니다.
- 내용이 빈 날(주말 등)은 건너뜁니다.
- 쉼표를 빠뜨린 `…(…) 다음활동(…)` 도 두 건으로 나눕니다.

잘못 읽힌 칸은 미리보기 표에서 고친 뒤 등록하면 됩니다.

## 글꼴·크기 바꾸기

[설정] 탭 → '결재용 한글 문서' 에서 글꼴(기본 `함초롬바탕`)과 크기(기본 11pt)를 바꿀 수 있습니다.
