## 초2 눈높이 점검 (Claude의 의견 — 교사 확인 필요)

기준: 풀이는 한두 문장, 풀이에 쓰는 말은 2학년 교과서·일상에서 쓰는 낱말로 했습니다. 어려울 수 있어 풀이에서 뺀 말: 겉껍질→딱딱한 껍질, 형제자매→형·누나·언니·동생, 상상 속→상상하는, 용비어천가→아주 오래된 책, 금성·우애(비슷한 말 칸)는 삭제.

다시 한번 봐 주세요.

| 낱말 | 걱정되는 점 | 대안 |
|---|---|---|
| 미리내 | ‘은하수’, ‘시냇물’ | 은하수는 비슷한 말로만 보여 줌. 어려우면 비슷한 말 칸을 지워도 됩니다. |
| 보늬 | ‘속껍질’ | 그림(밤)으로 떠올릴 수 있어 두었음. 실물 밤 사진이 있으면 더 좋습니다. |
| 마루 | 뜻이 두 가지(꼭대기 / 집 안 나무 바닥) | 앞은 풀이, 뒤는 ‘알아 두기’로 나눔. |
| 안다미로 | ‘넘칠 만큼’, ‘수북이’ | 그림(밥그릇)과 같이 보면 이해될 것으로 봄. |
| 아리아 | 사전에 없는 낱말. 풀이가 가장 긴 편 | 활동지의 뜻과 다르면 교체. |
| 아라 | 사전·문헌에 근거가 없다는 지적 | “~라고 알려져 있어요”로 단정을 피함. |
| 아리아·나르샤·다소니·슈룹 | 옛말이라 2학년에게는 처음 듣는 말 | 풀이는 쉬워도 예문을 읽어 보게 하면 좋습니다. |

## 풀이의 근거

- 뜻풀이는 표준국어대사전의 뜻을 바탕으로 2학년 말로 풀어 썼습니다. **다만 이 세션에서 사전을 직접 열어 한 낱말씩 대조하지는 못했습니다.** 수업 전에 국립국어원 표준국어대사전(stdict.korean.go.kr)에서 한 번 훑어봐 주세요.
- 인터넷 검색으로 확인된 것: 나르샤(날아오르다), 모꼬지(놀이·잔치로 여러 사람이 모이는 것).
- 사전에 없는 낱말: 아리아, 아라 (위 표 참고).
