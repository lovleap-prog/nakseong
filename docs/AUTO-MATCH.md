# 담당자 자동 매칭

일정을 불러올 때 **담당자와 부서를 알아서 채웁니다.** 설정 탭의
[담당자 자동 매칭] 상자에서 준비합니다.

## 두 가지 근거를 같이 씁니다

| | 무엇 | 성격 |
|---|---|---|
| **업무분장표** | '안전'·'학교폭력' 은 생활인성부 박지현 | 학교가 정한 **규칙**. 가장 믿을 만함 |
| **과거 사례** | 작년에 '소방대피 훈련' 을 누가 맡았나 | **통계**. 규칙에 없는 것을 메움 |

둘 중 하나만 써도 되지만, 같이 쓰면 훨씬 잘 맞습니다.
업무분장표는 새 활동에도 통하고, 과거 사례는 이름이 특이한 행사를 잡아냅니다.

> **외부 AI를 쓰지 않습니다.** API 키가 필요 없고, 교직원 명단이 학교 밖으로
> 나가지 않으며, 인터넷이 끊겨도 동작합니다. 학교 일정은 낱말이 정형화돼 있어서
> 글자 단위 유사도 비교만으로 충분히 맞습니다.

## 1. 업무분장표 넣기

**설정 → 담당자 자동 매칭 → [+ 사람 추가]** 또는 **[업무분장표 올리기]**

| 이름 | 부서/계 | 담당 업무 낱말 |
|---|---|---|
| 박지현 | 생활인성부 | 안전, 학교폭력, 소방, 대피, 생활지도 |
| 김서연 | 교무기획부 | 공개수업, 학부모, 교육과정, 평가 |
| 강도현 | 체육부 | 체육, 스포츠클럽, 운동회 |

**낱말을 잘 고르는 것이 전부입니다.**

- 구체적일수록 좋습니다. `학교폭력` 이 `교육` 보다 훨씬 정확합니다.
- `교육`, `활동`, `행사` 처럼 아무 데나 붙는 낱말은 넣지 마세요. 엉뚱하게 걸립니다.
- 낱말이 그대로 없어도 3글자 이상 겹치면 약한 근거로 인정합니다.
  (`스포츠클럽` 으로 `토요스포츠` 를 잡아냅니다)

파일로 올릴 때는 **성명 / 부서 / 담당업무** 열이 있는 표면 됩니다.
한글(.hwpx)·엑셀(.xlsx)·CSV 모두 받습니다.

## 2. 과거 계획으로 배우기

**설정 → 담당자 자동 매칭 → [과거 계획 파일 올리기]** (여러 개 한꺼번에 가능)

그동안 만든 주간학습계획·월중계획 한글 파일을 올리면 **활동명과 담당자 짝만 뽑아**
기억합니다. 일정으로 등록되지 않으니 지난 일정이 달력에 뜨지 않습니다.

> **파일에 담당자(또는 부서)가 적혀 있어야 배울 수 있습니다.**
> 담당자 열이 없는 주간학습계획은 배울 게 없어서 "짝을 찾지 못했습니다" 가 뜹니다.
> 그럴 때는 업무분장표 쪽에 힘을 주세요.

앱에서 **승인된 일정도 자동으로 사례가 됩니다.** 쓸수록 정확해집니다.

## 2-1. 무엇을 기억하나 — 매달 같은 것을 다시 치지 않도록

월중계획을 붙여넣으면 **날짜와 활동명만** 들어오고 나머지는 비어 있는 일이 많습니다.
그것을 손으로 채우신 것이 곧 정답이라, 그대로 쌓아 둡니다.

| 칸 | 기억하나 | 왜 |
|---|---|---|
| **담당 · 부서** | ○ | 같은 행사는 대개 같은 분이 맡습니다 |
| **분류** | ○ | 한 번 정하면 바뀌지 않습니다 |
| **장소** | ○ | `독도교육 무브퀴즈` 는 늘 백이관입니다 |
| **대상** | ○ | 늘 전교생이면 다음에도 전교생입니다 |
| 날짜 · 시간 | ✕ | **달마다 달라지는 것**이고, 월중계획에 적혀 들어옵니다 |
| 세부 내용 | ✕ | 그때그때 다릅니다 |

```
11월  11.5(목)  독도교육 무브퀴즈   [  ] [    ] [    ]   ← 비어 있어 손으로 채움
                                    전교생  백이관  조요한
      ↓ 등록 (기억하기 체크)
12월  12.3(목)  독도교육 무브퀴즈   전교생  백이관  조요한   ← 저절로 채워짐
```

읽어들인 뒤 쪽지에 `전에 적으신 장소·대상 N건을 되살렸습니다` 라고 나옵니다.

**이미 적혀 들어온 칸은 덮지 않습니다.** 월중계획에 `3학년 / 도서관` 이라고 적혀 있으면
그대로 둡니다. 되살리는 것은 **빈 칸뿐**입니다.

> **장소·대상은 활동명이 똑같을 때만** 되살립니다.
> 담당자는 `소방` 같은 낱말만 걸려도 짐작할 거리가 되지만, 장소를 비슷한 이름의 다른
> 행사에서 끌어오면 그냥 틀린 값이 들어갑니다. `독도교육 무브퀴즈` 로 배운 것이
> `독도교육 골든벨` 에 들어가지 않습니다.

기억한 것은 **[설정] → 담당자 자동 매칭** 에서 보고 지울 수 있습니다
(`사례 12종 / 31건` 처럼 나옵니다).

## 3. 어떻게 판단하는지

| 표시 | 뜻 | 동작 |
|---|---|---|
| **자동 · 확실** | 근거가 뚜렷하고 2등과 차이가 큼 | 담당자 칸에 바로 채움 |
| **자동 · 보통** | 근거는 있음 | 담당자 칸에 바로 채움 |
| **제안: 홍길동** | 근거가 약함 | **채우지 않음.** 눌러야 들어감 |
| (아무것도 없음) | 근거 없음 | 비워둠 |

**틀린 이름이 채워져 있는 것보다 비어 있는 편이 낫다**는 원칙입니다.
비어 있으면 눈에 띄어 고치지만, 틀린 이름은 그대로 결재까지 갑니다.

칸에 마우스를 올리면 **왜 그렇게 추천했는지** 나옵니다.
(`업무분장 '소방' · 과거 '소방대피 훈련'`)

활동명·세부내용에서 걸린 근거는 온전히 인정하고, **장소·대상에서 걸린 근거는 절반만**
인정합니다. 'AI교실' 에서 수업한다고 정보 담당자가 맡는 건 아니기 때문입니다.

## 4. 시험해 보기

설정 탭 맨 아래 칸에 활동명을 쳐보면 누구를 추천하는지 바로 보입니다.
업무분장 낱말을 다듬을 때 쓰세요.

## 잘 안 맞을 때

| 증상 | 손볼 곳 |
|---|---|
| 아무도 추천 안 됨 | 업무분장 낱말이 너무 적거나 일반적임. 활동명에 실제로 들어가는 낱말로 |
| 엉뚱한 사람이 걸림 | `교육`, `학교` 같은 흔한 낱말을 뺄 것 |
| 특정 행사만 계속 틀림 | 그 행사를 한 번 직접 고쳐서 승인하면 다음부터 사례로 학습됨 |

## 주간활동계획 한글 파일로 배우기

학교에서 쓰던 **주간활동계획**을 그대로 올리면 됩니다. 이런 표를 읽습니다.

| 날짜(요일) | 계 | 담당자 | 주요 업무 내용 | 시간 | 장소 |
|---|---|---|---|---|---|
| 3.16 (월) | 생활 인성 | | 학부모상담주간(~20) | | |
| 3.17 (화) | 체육 | | 학교스포츠클럽 | 10:30 | 각 장소 |

- **계(부서)와 담당자를 둘 다** 봅니다. 담당자 칸이 비어 있어도 계만 있으면 배웁니다
- 날짜 칸이 세로로 병합돼 있어도 아래 줄까지 같은 날로 이어 읽습니다
- `생활 ⏎ 인성` 처럼 두 줄로 쓰인 부서 이름은 한 줄로 붙입니다
- 내용 칸이 `제목 ⏎ - 세부 ⏎ - 세부` 면 **첫 줄만 제목**으로 삼고 나머지는 세부 내용으로 내립니다
- 파일 뒤에 딸려 오는 **교담 시간표는 건너뜁니다.** 일정이 아니기 때문입니다
  (그 표는 [시간표] 탭에서 따로 올리세요)

> 주간활동계획의 머리글은 `담당자` 와 `주요 업무 내용` 을 함께 담고 있어서
> 한때 업무분장표로 오해해 통째로 버리고 있었습니다. 지금은 **날짜 열이 있는지**로
> 둘을 가릅니다. 업무분장표에는 날짜 열이 없습니다.
